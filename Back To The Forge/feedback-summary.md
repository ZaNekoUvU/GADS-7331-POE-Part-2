## Recurring Themes

### Raised by both playtesters

- **Wayfinding** — Need for visual guidance on where to go (paths, pathing).
- **Random encounters** — Frequency felt too high; source of frustration.
- **Controls & objectives** — Not self-explanatory; required team explanation during playtest.
- **Combat targeting** — Both were confused as to which enemy they were targeting.

### Positive overlap

- **Art style** — Both responded positively (liked / cute).

### Single-reporter items (not repeated by the other playtester)

- UI legibility under impaired vision (Farrell).
- Combat simplicity appreciated (Farrell).
- Cool/different concept noted positively (Farrell).
- In-game UI appearing on main menu — bug reported (Farrell).
- Placeholder assets breaking immersion (Mia).
- Flee button reliability (Mia).
