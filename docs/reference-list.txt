IN-TEXT CITATION EXAMPLES (for common sources in this project)
================================================================================

Software and tools
------------------
Turn-based combat runs in an additively loaded Unity scene (Unity Technologies, 2025).
Optional dialogue is generated locally through Ollama (Ollama, 2024) using the Qwen3 8B model (Qwen Team, 2025).
Implementation support used Cursor IDE agents (Anysphere, 2026).

Third-party art
---------------
Overworld tilemaps use the Minifantasy forgotten plains pack (Palacio, 2026).

AI-generated character and environment art
------------------------------------------
The player walk animations use sprite sheets generated by Auto (2026a).
Village NPC visuals were produced as AI-generated digital images (Auto, 2026b).
Mercenary roster art includes walk sheets and battle-ready portraits (Auto, 2026d; Auto, 2026e).
Enemy combat portraits were generated for goblin, ogre, slime, and bandit units (Auto, 2026f).

Referencing style
-----------------
Citations in the written submission should follow The Independent Institute of Education (2025).
