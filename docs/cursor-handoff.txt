1. GAME LOOP (FOR CONTEXT)
--------------------------------------------------------------------------------

- Exploration: top-down 2D, mine/chop IronVein nodes (hold E), inventory (hold Tab), talk to NPCs/blacksmith.
- Forge quest: Blacksmith commissions Ollama-invented ore name → pickup in world → also needs supplementary ore (e.g. Iron) → turn-in → optional end day.
- Combat: additive load of Combat Scene; exploration stays loaded; coordinator hides non-combat rendering.
- Mercenaries: hired at camp (max 3), follow player, Ollama chat via C-key party menu (not E in field).
- Economy: BlacksmithMaster — gold, daily market, sell-all on end day.

4. QUEST LOG OBJECTIVE FLOW
--------------------------------------------------------------------------------

1. No active quest: "Visit the blacksmith for work."
2. Quest active, no commission ore yet: "Find {QuestMaterialName} resource."
3. Has commission ore: "Return {QuestMaterialName} to the blacksmith."
4. After turn-in: "Continue exploring."
5. If supplementary ore required and missing: "Collect {Iron DisplayName} from the mines."

Quest log hidden when CombatAdditiveCoordinator.IsCombatActiveOrLoading.


5. WAYPOINT ARROW FLOW
--------------------------------------------------------------------------------

1. No quest / need blacksmith → blacksmith
2. Quest active, main ore not collected → quest mineral spawn
3. Main ore collected, supplementary missing → nearest matching IronVein
4. Otherwise → blacksmith (turn-in)


6. EXPLORATION CONTROLS
--------------------------------------------------------------------------------

WASD / arrows     Move
E                 Interact (NPCs, dialogue, hold to gather) — NOT hired mercs
C                 Talk to hired mercenary (party picker → Ollama chat)
Tab (hold)        Inventory + gold
Enter / Z         Confirm menu / dialogue
Esc / P           Pause
Esc / X           Cancel choice menu
