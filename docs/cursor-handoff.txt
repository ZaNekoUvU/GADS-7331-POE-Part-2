1. GAME LOOP (FOR CONTEXT)
--------------------------------------------------------------------------------

- Exploration: top-down 2D, mine/chop IronVein nodes (hold E), inventory (hold Tab), talk to NPCs/blacksmith.
- Forge quest: Blacksmith commissions Ollama-invented ore name → pickup in world → also needs supplementary ore (e.g. Iron) → turn-in → optional end day.
- Combat: additive load of Combat Scene; exploration stays loaded; coordinator hides non-combat rendering.
- Mercenaries: hired at camp, follow player, Ollama opening lines use persona from hire offer.
- Economy: BlacksmithMaster — gold, daily market, sell-all on end day.

3. QUEST LOG OBJECTIVE FLOW (EXACT BEHAVIOR)
--------------------------------------------------------------------------------

1. No active quest: "Visit the blacksmith for work."
2. Quest active, no commission ore yet: "Find {QuestMaterialName} resource."
3. Has commission ore (picked up / in inventory): "Return {QuestMaterialName} to the blacksmith."
4. After turn-in, nothing left to fetch: "Continue exploring."
5. If supplementary ore required and missing: extra line "Collect {Iron DisplayName} from the mines."

Quest log hidden when CombatAdditiveCoordinator.IsCombatActiveOrLoading.


4. WAYPOINT ARROW FLOW
--------------------------------------------------------------------------------

1. No quest / need blacksmith → blacksmith
2. Quest active, main ore not collected → quest mineral spawn (QuestMineralSpawner)
3. Main ore collected, supplementary missing → nearest IronVein matching ForgeIronTurnInItem
4. Otherwise → blacksmith (turn-in)

Arrow: QuestWaypointArrow.cs — procedural triangle, ~55% scale, tip points toward target, orbits player in LateUpdate.

   (ambiguous with System.Object when using System;).

   trigger-only detection, UI layout. Fixed by: UI on player + TryGetGatherNodeAtPosition.
